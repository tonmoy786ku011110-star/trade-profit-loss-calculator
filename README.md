# Trade Profit/Loss Calculator

একটি সহজ এবং দ্রুত ডেস্কটপ অ্যাপ্লিকেশন যা আপনার ট্রেডিং লাভ এবং ক্ষতি স্বয়ংক্রিয়ভাবে হিসাব করে।

## বৈশিষ্ট্য

✅ **ট্রেড এন্ট্রি যোগ করুন** - Entry Price, Exit Price, Quantity সহজে ইনপুট করুন
✅ **স্বয়ংক্রিয় হিসাব** - লাভ/ক্ষতি তাৎক্ষণিক ক্যালকুলেট হয়
✅ **সম্পূর্ণ ট্রেড ইতিহাস** - সব ট্রেড এর রেকর্ড দেখুন
✅ **মোট লাভ/ক্ষতি** - সমস্ত ট্রেড এর সারমর্ম
✅ **পরিসংখ্যান** - সফল/ব্যর্থ ট্রেড, Win Rate ইত্যাদি
✅ **ডেটা সংরক্ষণ** - CSV ফরম্যাটে সেভ করুন

## ইনস্টলেশন

### প্রয়োজনীয়তা
- Python 3.7 বা তার উপরে
- pip (Python package manager)

### ধাপ ১: রিপোজিটরি ক্লোন করুন

```bash
git clone https://github.com/tonmoy786ku011110-star/trade-profit-loss-calculator.git
cd trade-profit-loss-calculator
```

### ধাপ ২: ডিপেন্ডেন্সি ইনস্টল করুন

```bash
pip install -r requirements.txt
```

### ধাপ ৩: অ্যাপ্লিকেশন চালান

```bash
python main.py
```

## ব্যবহার

1. **অ্যাপ্লিকেশন খুলুন** - `python main.py` চালান
2. **ট্রেড তথ্য ইনপুট করুন**:
   - Entry Price (প্রবেশ মূল্য)
   - Exit Price (বেরিয়ে যাওয়ার মূল্য)
   - Quantity (পরিমাণ)
3. **"Add Trade"** বাটনে ক্লিক করুন
4. **ফলাফল দেখুন** - লাভ/ক্ষতি স্বয়ংক্রিয়ভাবে গণনা হয়েছে
5. **ডেটা সেভ করুন** - "Save to CSV" বাটনে ক্লিক করুন

## ফাইল কাঠামো

```
trade-profit-loss-calculator/
├── main.py                 # মূল অ্যাপ্লিকেশন
├── requirements.txt        # পাইথন ডিপেন্ডেন্সি
├── README.md              # এই ফাইল
└── trades.csv            # ট্রেড ডেটা (স্বয়ংক্রিয়ভাবে তৈরি)
```

## উদাহরণ

**ট্রেড ১:**
- Entry Price: 100 টাকা
- Exit Price: 120 টাকা
- Quantity: 10
- লাভ: (120-100) × 10 = **200 টাকা** ✅

**ট্রেড ২:**
- Entry Price: 150 টাকা
- Exit Price: 140 টাকা
- Quantity: 5
- ক্ষতি: (140-150) × 5 = **-50 টাকা** ❌
